## What is here that matters to The Gaming Layer

1. **The layer is not the owner's first attempt at this.** Six micro-games — Rice Milker,
   Sip Drip, Water Vibrate, Roasted Bean, Acorn Tap, Chew Pay — were each designed as a
   "RUHBI Payroll Integration Point System", i.e. a game wired to a payout. That is exactly
   the pattern the layer's rules now forbid inside a loop (powers raise what you can *do*,
   never what the game *pays*). Worth reading before any studio conversation, as the
   cautionary version.
2. **The 8-bit house style already exists** in these files — the particle and canvas toys
   are the same visual family as Bin Runner and KETTLE LANE.
3. **Nothing in this library is Gaming Layer strategy.** No ratified layer documents, no
   studio contacts, no pricing. The layer's own sources stay where they are: the plan,
   `../specs/`, and the game folders.
