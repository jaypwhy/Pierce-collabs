## **Game Concept Overview**

**"Rice Milker"** is a **3D physics-based puzzle game** where players manipulate floating rice grains (spheres) in a virtual paddy field to achieve goals like:

*   **Harvesting rice** by guiding grains into a basket
    
*   **Creating patterns** (e.g., golden ratio spirals, pi grids)
    
*   **Avoiding obstacles** (e.g., water puddles, birds)
    
*   **Competing in time trials** or against AI farmers
    

The game blends **physics, spatial reasoning, and light strategy**—perfect for a relaxing yet engaging mobile/desktop experience.

* * *

## **Core Mechanics (Like Your Sphere App, But Rice-Themed!)**

### **1. Game World & Physics**

*   **Environment**: A **3D paddy field** with:
    *   **Rice grains** (spheres) floating in mid-air (like your spheres).
        
    *   **Wind currents** (gentle forces pushing grains).
        
    *   **Water puddles** (slippery zones that slow movement).
        
    *   **Birds** (obstacles that peck at grains).
        
*   **Physics Engine**:
    *   Grains can be **pushed, pulled, or rotated** (like your sphere dragging).
        
    *   **Gravity** pulls grains downward (but they float slightly).
        
    *   **Collisions** with obstacles (e.g., birds scatter grains).

* * *

### **3. Game Modes (Like Your UI Buttons, But Fun!)**

#### **A. "Harvest Mode" (Puzzle)**

*   **Goal**: Guide **N grains** into a **basket** (fixed position).
    
*   **Rules**:
    *   Grains **float upward** over time (like bubbles).
        
    *   **Wind pushes grains** randomly.
        
    *   **Birds** (enemies) peck at grains if they get too close.
        
*   **Win Condition**: All grains reach the basket within time limits.
    

#### **B. "Pattern Maker" (Creative)**

*   **Goal**: Recreate a **target pattern** (e.g., golden spiral, pi grid).
    
*   **Rules**:
    *   Grains must align in **specific positions**.
        
    *   **Drag and rotate** grains to match the pattern.
        
    *   **Time-based scoring** (faster = better).
        

#### **C. "Time Trial" (Competitive)**

*   **Goal**: Harvest **as many grains as possible** in **60 seconds**.
    
*   **Rules**:
    *   Grains spawn randomly.
        
    *   **Wind speed increases** over time.
        
    *   **Birds multiply** if you fail to harvest.
        
*   **Leaderboard**: Compare scores with friends.
    

#### **D. "Rice Battle" (Multiplayer)**

*   **Goal**: **Steal grains** from an opponent’s field while protecting yours.
    
*   **Rules**:
    *   Two players control **opposing wind currents**.
        
    *   **Grains can be "stolen"** by pushing them into the opponent’s basket.
        
    *   **Last grain standing wins!**

### **Key Changes from Your Sphere App:**

1.  **Replace spheres with rice grains**:
    *   Use **semi-transparent yellow spheres** with **brown highlights** (like real rice).
        
    *   Add **particle effects** (dust, water ripples) for immersion.
        
2.  **Physics Engine**:
    *   Use **Three.js + Cannon.js** (or **Ammo.js**) for realistic floating physics.
        
    *   Add **wind forces** (`THREE.Vector3` for gentle pushes).
        
3.  **Obstacles & Enemies**:
    *   **Birds**: Small 3D models that peck at grains (use **THREE.Mesh** with collision).
        
    *   **Water Puddles**: Slippery zones that slow grain movement.
        
4.  **Pattern Recognition**:
    *   Use **Euclidean distance checks** to verify if grains match the target layout.
        
5.  **Multiplayer (Optional)**:
    *   **WebSocket** for real-time battles (like your sphere dragging but competitive).

// Replace your sphere creation with rice grains
function createRiceGrain() {
  const geometry = new THREE.SphereGeometry(0.3, 32, 32);
  const material = new THREE.MeshStandardMaterial({
    color: new THREE.Color(0xF5DEB3), // Rice color
    roughness: 0.2,
    metalness: 0.1,
    transparent: true,
    opacity: 0.8,
    side: THREE.DoubleSide
  });
  const grain = new THREE.Mesh(geometry, material);
  grain.castShadow = true;
  grain.receiveShadow = true;
  grain.userData = {
    originalPosition: grain.position.clone(),
    isHarvested: false
  };
  scene.add(grain);
  return grain;
}
// Wind force function
function applyWindForce(grain) {
  const windDirection = new THREE.Vector3(
    (Math.random() - 0.5) * 0.1, // X-axis wind
    0.01, // Gentle upward drift
    0
  );
  grain.applyForce(windDirection, grain.position);
}
